Dựa vào [[02. Process#ps_auxwwwf.txt]], process command là:
```
./scripts/../vendor/bin/.cache/update
```
Để tìm thông tin full process path, ta sẽ sử dụng `/proc/5241/` như ở [[02. Process#/proc/5241/environ.txt]]
```
/home/irek/Documents/mcp-connector-hub
```
Resolve path:
```
/home/irek/Documents/mcp-connector-hub
└── ./scripts/../
    └── vendor/bin/.cache/update
```
`./scripts/../` tương đương với thư mục hiện tại, nên **full path của process** là:
```
/home/irek/Documents/mcp-connector-hub/vendor/bin/.cache/update
```
Hoặc có thể đọc trực tiếp từ [[02. Process#running_processes_full_paths.txt]]
