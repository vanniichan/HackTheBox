Để trả lời cho câu hỏi này, ta sẽ dựa vào `auth.log`, đây là nơi có thể xác định được khi nào một phiên root được spawn. Để ý ta sẽ thấy điều bất thường tại [[06. root folder#auth.log.1]] khi process tạo phiên root mang tên `.telnet`
```
Apr  7 19:06:27 poleska login[5518]: pam_unix(login:session): session opened for user root(uid=0) by .telnet(uid=0)
```
Thời gian này mình tưởng sai nhưng mà là do log này đang theo local time [[06. root folder#timezone]], ta cần chuyển về UTC
```
2026-04-07 17:06:27
```
